# SELA · Latihan Cumex

Website latihan interaktif Cumex Blok I.1 dan I.2.

Website: https://xynatez.github.io/sela-latihan-cumex/

## Fitur

- Bank soal dan pembahasan
- Simulasi ujian
- Flashcard
- Hasil latihan dan cadangan progres

Progres tersimpan pada browser masing-masing menggunakan localStorage.

## Menjalankan secara lokal

Buka `index.html` di browser, atau jalankan server statis dari direktori ini:

```sh
python -m http.server 8080
```

GitHub Pages diterbitkan dari branch `main`, direktori root.
